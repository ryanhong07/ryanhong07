### 2. Real-Time Sound Source Localization and Tracking System
Repository: [ryanhong07/real-time-SSL-and-tracking](https://github.com/ryanhong07/real-time-SSL-and-tracking)

This project implements a robotic “hearing” system capable of detecting the direction of a sound source and orienting a platform toward it in real time. It combines embedded systems, DSP, and mechatronics into a compact robotic platform.

Highlights:
- Uses a NUCLEO-U083RC microcontroller and two analog microphones
- Real-time sound localization using time-difference-of-arrival (TDOA) and cross-correlation
- Embedded digital signal processing for noise filtering and detection
- Servo-based tracking system to rotate toward the sound source
- Finite-state machine for listening, computation, actuation, and recovery logic

Key skills:
- Embedded C / STM32 firmware
- Signal processing and audio feature extraction
- Real-time control
- Hardware-software integration
- Sensor fusion and actuation logic

### 3. Autonomous Drone Cave Exploration System
Repository: [ryanhong07/FinalProjectAutonomousSystem](https://github.com/ryanhong07/FinalProjectAutonomousSystem)

This project is a ROS 2 autonomous drone system for exploring and mapping a cave-like environment using OctoMap and frontier-based exploration. It is based on the RoboCrafty final project structure and extends autonomous navigation, perception, and exploration logic for a simulated underground environment.

Highlights:
- ROS 2 Jazzy-based autonomous exploration stack
- OctoMap-based 3D mapping and occupancy planning
- Frontier-based exploration strategy
- Decision-making finite-state mission logic
- Trajectory generation and autonomous waypoint execution
- Lantern hunting / target pursuit behavior as part of the mission flow

Key skills:
- ROS 2 and autonomous navigation
- 3D mapping and perception
- Mission planning and state machines
- Path planning and trajectory generation
- Autonomous systems integration
